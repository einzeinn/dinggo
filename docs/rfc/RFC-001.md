# RFC-001: Mandatory Documentation Prior to Large Scope Changes

**Status:** Active  
**Applies to:** All AI agents and developers working on this repository

## Background

This project is built using automated and agentic AI workflows. Without an explicit rule, large modifications (architecture, core dependencies, folder structures, or major technical decisions) risk being implemented without traceability — making it difficult to maintain and understand the rationale behind past decisions.

## Rule

**Every architectural change, major feature addition, or significant scope expansion MUST be documented prior to writing implementation code.**

### Criteria for "Significant Scope"

Includes (but is not limited to):
- Adding or swapping models/layers in the orchestration pipeline
- Modifying core directory structures (`core/`, `tools/`, `cli/`)
- Introducing major new external dependencies
- Altering the core lifecycle loop (Reason → Plan → Confirm → Execute)
- Irreversible architectural decisions (data formats, configuration schemas)

**Exempt from prior documentation** (may proceed directly to execution):
- Minor bug fixes, typos, formatting
- Single-file edits with clear, localized, and reversible scope
- Isolated scratch/experimental scripts

### Procedure

1. If a task meets the "Significant Scope" criteria, the agent MUST **pause before implementing source code changes**.
2. Document the decision concisely in `docs/07-TechnicalDecisions.md` (using the `TD-XXX` format) OR create a new RFC (`RFC-002.md`, etc.) if the scope requires a dedicated specification.
3. After the documentation is established, proceed to the implementation plan, approval gate, and execution.
4. Update `CHANGELOG.md` or walkthrough artifacts upon completion.

## Examples

| Scenario | Prior Documentation Required? | Action |
| :--- | :--- | :--- |
| Swapping the planner model | Yes | Update `TD-003` in `07-TechnicalDecisions.md` |
| Adding a new tool (e.g. `search_code`) | Yes | Update `06-Architecture.md` + new TD entry |
| Fixing a relative path bug in `file_ops.py` | No | Direct fix + test verification |
| Adjusting UI panel padding/colors | No | Direct fix + test verification |
| Restructuring `tools/` into sub-packages | Yes | Update `06-Architecture.md` |
